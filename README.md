# Predictive Tourism

A web-based Predictive Tourism application developed using Python, Flask, HTML, CSS, and SQLite. The application provides tourism-related information and prediction-based functionalities through a user-friendly web interface.

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- Machine Learning

## Project Features

- Tourism-related information
- Database integration
- Predictive functionality
- User-friendly web interface
- Backend processing using Flask

## Project Structure

- `app.py` – Main Flask application
- `database.py` – Database operations
- `style.css` – Website styling
- `tourism.db` – SQLite database
- `data/` – Dataset files
